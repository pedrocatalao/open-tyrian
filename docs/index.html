OpenTyrian

The classic vertical shooter, reborn.

An open-source port of Tyrian, the 1995 DOS arcade shooter. Everything you need to play is in the download, including the freeware game data. Free for Windows, macOS, and Linux.

Features

Arcade action

Fast, dense, hand-built levels full of bullets, bosses, and destructible scenery.

Deep upgrades

Spend your credits on front and rear guns, sidekicks, shields, and power generators.

Branching missions

Choose your route through the galaxy and hunt down the secret levels.

Two players

Story mode, one- and two-player arcade, and head-to-head network play.

Every build includes the freeware Tyrian 2.1 game data, so there is nothing else to download.

The macOS app isn't notarized. If Gatekeeper blocks it, right-click the app, choose Open, and confirm once.

Saves and settings live in %APPDATA%\OpenTyrian on Windows and ~/.config/opentyrian on macOS and Linux.

Looking for older versions? See all releases.

Build it yourself

You need a C99 compiler, GNU make, pkg-config, and SDL2. Network play is turned on automatically when SDL2_net is available. A Visual Studio solution is included for Windows.

# clone and build
git clone https://github.com/opentyrian/opentyrian
cd opentyrian
make
./opentyrian
